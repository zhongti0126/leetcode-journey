# Day 5 Notes

## Tree DFS
- Each node has:
  - val
  - left
  - right

## Important Concepts
- root = top
- left = left child
- right = right child
- left = node with no children 

## DFS (Depth First Search)

### Preorder Traversal
- self
- left
- right

Example:

```text
    1
   / \
  2   3
```

DFS Order:

```text
1 → 2 → 3
```
